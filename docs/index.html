Free plugin for product managers

PM OS

Give your AI a workspace that remembers your product, your decisions, and how you like to work. It keeps itself organized.

Download the PM OS plugin (.zip)

No terminal needed. Keep the file zipped: that is the file you upload. One file works in both Claude and ChatGPT.

Set it up in about a minute

Claude desktop app or claude.ai
  1. Open Customize → Plugins.
  2. Click + Add, then Upload plugin.
  3. Choose pm-os-plugin.zip.
  4. Start a chat and say “Set up a PM OS for my product.”
ChatGPT desktop app
  1. Open Customize → Plugins.
  2. Click Add, then Upload plugin archive.
  3. Choose pm-os-plugin.zip.
  4. Start a chat and say “Set up a PM OS for my product.”

Get the full workspace

PM OS works best when your AI can save files to a folder on your computer. In the Claude desktop app, start a Cowork task and pick an empty folder (for example Documents/my-product), then ask it to set up PM OS. It builds your product folders, a living workboard, and a Chief PM agent that keeps everything filed.

In a regular web chat with no folder, PM OS still helps: it keeps a running index in the conversation and tells you clearly that nothing was saved to disk.

Then just talk to it

“Here are my notes from today’s customer call.” It files a summary, keeps your raw notes, and logs the decision.

“What should we build first?” It answers from what it already knows, with reasons.

“Customize my workspace.” It asks a few questions and tailors folders, templates, and specialists to your product.

Troubleshooting

  • You ended up with a folder, not a .zip. Some browsers (Safari) unzip downloads automatically. Right-click the pm-os-plugin folder and choose Compress, then upload the new .zip.
  • Claude can't run the setup. Open Settings → Capabilities and turn on Code execution and file creation. On Team or Enterprise plans, an owner may need to allow plugin uploads.
  • No upload option in ChatGPT on the web. There, plugin uploads are limited to workspace admins (Admin → Plugins). Use the ChatGPT desktop app instead.
  • The plugin doesn't start. Say “Use pm-os-setup to set up a PM OS for my product.”
  • Prefer to add it as a skill? Download pm-os-setup.zip and upload it under Customize → Skills in Claude, or Plugins → Skills → Create → Upload from your computer in ChatGPT.

Prefer the terminal?

Install for Claude Code, Codex, Cursor, and other coding agents with one command:

npx skills@latest add manansuneja/skills --skill pm-os-setup -g

Source, release notes, and every other install path live on GitHub.

Plain files by design

PM OS creates a plain-Markdown home for your vision, customer context, meetings, decisions, outcomes, and PRDs. It has no account connection, hosted service, telemetry, or server of its own. Free and open source under the MIT license.
