Free plugin for product managers

PM OS

Give your AI a workspace that remembers your product, your decisions, and how you like to work. It keeps itself organized.

Download the PM OS plugin (.zip)

No terminal needed. One file works in Claude, ChatGPT, Cursor, and VS Code. For Claude and ChatGPT, upload the .zip file itself.

On a Mac with Safari? Safari unzips downloads into a folder, and the folder won't upload. Before you click, open Safari → Settings → General and turn off Open “safe” files after downloading, or download with Chrome, Edge, or Firefox. Don't re-zip the folder with Compress: macOS adds hidden files that Claude and ChatGPT reject.

Set it up in about a minute

Claude desktop app or claude.ai
  1. Open Customize → Plugins.
  2. Click + Add, then Upload plugin.
  3. Choose pm-os-plugin.zip.
  4. Start a chat and say “Set up a PM OS for my product.”
ChatGPT desktop app
  1. Open Customize → Plugins.
  2. Click Add, then Upload plugin archive.
  3. Choose pm-os-plugin.zip.
  4. Start a chat and say “Set up a PM OS for my product.”

In your code editor

Engineers and PMs who live in an editor can add the same plugin to Cursor or VS Code. Unzip pm-os-plugin.zip first; you get a pm-os-plugin folder.

Cursor
  1. Move the pm-os-plugin folder into ~/.cursor/plugins/local/. On a Mac, in Finder press ⇧⌘G and paste ~/.cursor/plugins/local. On Windows, open %USERPROFILE%\.cursor\plugins\local.
  2. In Cursor, open the Command Palette (⇧⌘P or Ctrl+Shift+P) and run Developer: Reload Window.
  3. Open Customize and check that PM OS is listed.
  4. Open an empty folder and ask the agent “Set up a PM OS for my product.”

On Teams and Enterprise, an admin may need to turn on Allow Local Plugin Imports. Terminal instead: npx skills@latest add manansuneja/skills --skill pm-os-setup -g -a cursor

VS Code GitHub Copilot
  1. Move the pm-os-plugin folder somewhere it can stay, such as Documents.
  2. Open the Command Palette (⇧⌘P or Ctrl+Shift+P), run Preferences: Open User Settings (JSON), and add these lines with your folder's path: 
    "chat.plugins.enabled": true,
"chat.pluginLocations": {
  "/Users/you/Documents/pm-os-plugin": true
}
  3. Run Developer: Reload Window, then Chat: Open Customizations and check the Plugins tab for PM OS.
  4. Open an empty folder and ask Copilot in agent mode “Set up a PM OS for my product.”

On Windows, write the path with forward slashes, like C:/Users/you/Documents/pm-os-plugin. Terminal instead: npx skills@latest add manansuneja/skills --skill pm-os-setup -g -a github-copilot

Get the full workspace

PM OS works best when your AI can save files to a folder on your computer. In Cursor and VS Code, that is simply the folder you open. In the Claude desktop app, start a Cowork task and pick an empty folder (for example Documents/my-product), then ask it to set up PM OS. It builds your product folders, a living workboard, and a Chief PM agent that keeps everything filed.

In a regular web chat with no folder, PM OS still helps: it keeps a running index in the conversation and tells you clearly that nothing was saved to disk.

Then just talk to it

“Here are my notes from today’s customer call.” It files a summary, keeps your raw notes, and logs the decision.

“What should we build first?” It answers from what it already knows, with reasons.

“Customize my workspace.” It asks a few questions and tailors folders, templates, and specialists to your product.

Troubleshooting

  • You ended up with a folder, not a .zip. Safari unzipped it. For Cursor or VS Code, the folder is exactly what you need. For Claude or ChatGPT, delete the folder, turn off Safari → Settings → General → Open “safe” files after downloading (or use another browser), and download again. Re-zipping with Compress doesn't work: macOS adds a hidden __MACOSX folder that both apps reject.
  • PM OS doesn't show up in Cursor or VS Code. Check that the folder you moved contains a skills folder directly inside it (not another pm-os-plugin folder), then reload the window.
  • Claude can't run the setup. Open Settings → Capabilities and turn on Code execution and file creation. On Team or Enterprise plans, an owner may need to allow plugin uploads.
  • “Couldn't add plugin” or “missing .claude-plugin/plugin.json”. The file you uploaded isn't the original plugin zip. Usually it's a folder that was re-zipped with Compress, or the skill-only zip. Download pm-os-plugin.zip again (see the Safari note above) and upload that file as is.
  • No upload option in ChatGPT on the web. There, plugin uploads are limited to workspace admins (Admin → Plugins). Use the ChatGPT desktop app instead.
  • The plugin doesn't start. Say “Use pm-os-setup to set up a PM OS for my product.”
  • Prefer to add it as a skill? Download pm-os-skill.zip (skill only, not a plugin) and upload it under Customize → Skills in Claude, or Plugins → Skills → Create → Upload from your computer in ChatGPT.

Prefer the terminal?

Install the skill for Claude Code, Codex, Cursor, VS Code, and other coding agents with one command. Add -a cursor or -a github-copilot to target Cursor or VS Code:

npx skills@latest add manansuneja/skills --skill pm-os-setup -g

Plain files by design

PM OS creates a plain-Markdown home for your vision, customer context, meetings, decisions, outcomes, and PRDs. It has no account connection, hosted service, telemetry, or server of its own. Free and open source under the MIT license.
