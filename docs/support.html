How can I help?

For setup problems, unexpected behavior, safety concerns, or feature requests, open a public issue in the skills repository.

Open a GitHub issue

Please include the plugin name and version, the prompt you used, your agent client, expected behavior, and what happened. Remove private product information before posting.

Security-sensitive reports should avoid public reproduction data. Start with a minimal issue asking for a private contact route.
