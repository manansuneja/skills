# outcomes/ — Index

> **Your product content:** Durable synthesis, recommendations, and next steps.

Outcome artifacts live here: insights, recommendations, prioritization memos, MVP cuts, trade-off
analyses, and next-step plans. These are the durable answers created from product context.

| Date | Outcome | File |
|---|---|---|
| _none yet_ | Ask the Chief: "what insights should I draw from this?" or "prioritize the top 3" | - |

Use outcomes when the PM asks for thinking, synthesis, ranking, recommendations, or what to do next.
If an outcome becomes a committed choice, add a decision in `product-docs/decisions/`. If it becomes
buildable scope, create or update the project and its PRD in `product-docs/projects/`. An outcome
about a single project is filed inside that project; this folder holds product-wide outcomes.
